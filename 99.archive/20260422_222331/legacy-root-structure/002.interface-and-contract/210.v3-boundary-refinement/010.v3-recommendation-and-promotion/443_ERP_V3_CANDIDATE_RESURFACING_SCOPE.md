# ERP V3 CANDIDATE RESURFACING SCOPE
# ============================================================

status: canonical-draft
system: erp
owner: Boss
prepared_by: Zero

purpose:
Defines the scope for the v3 candidate resurfacing pass.

inside_scope:
- previously deferred candidates
- not-yet-promoted candidate layers
- unresolved cross-domain candidate themes
- candidates implied by audit/business/management/analytics expansion
- authority-adjacent but unpromoted structures

outside_scope:
- already-connected current design sets as final outputs
- unrelated fresh feature ideation without ERP grounding
- implementation-level tasks
- patch-only housekeeping

candidate_types:
- domain candidates
- cross-domain lifecycle candidates
- authority-layer candidates
- boundary/refinement candidates
- derived insight/control candidates

conclusion:
The resurfacing pass should focus on grounded next-stage candidates,
not arbitrary new ideas.
