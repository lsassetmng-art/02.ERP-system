# POSITIONING

This integration summary positions the family as:

- MRP for material and timing planning
- WMS for physical warehouse execution
- SCM for broader network and continuity coordination

The integration layer exists to define:
- handoff semantics
- reference linkage
- operational sequence
- exception routing
- reporting alignment


# NON POSITIONING

This layer is not:
- a new fourth operational module
- a replacement for MRP, WMS, or SCM
- a hidden monolith
- an excuse to blur ownership
