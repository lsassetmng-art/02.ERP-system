# RULE

Knowledge lookup may justify playbook recommendation,
but knowledge-article truth does not disappear.

Progression should preserve:
- linked article reference
- failure and incident scope visibility
- recommendation confidence visibility
- freshness visibility
- rejected recommendation trace when applicable
