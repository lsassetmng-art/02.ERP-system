# RULE

Playbook recommendation may justify runbook activation,
but recommendation truth does not disappear.

Progression should preserve:
- linked playbook reference
- recommended runbook template visibility
- activation reason visibility
- accepted or rejected timing visibility
- expiration trace when applicable
