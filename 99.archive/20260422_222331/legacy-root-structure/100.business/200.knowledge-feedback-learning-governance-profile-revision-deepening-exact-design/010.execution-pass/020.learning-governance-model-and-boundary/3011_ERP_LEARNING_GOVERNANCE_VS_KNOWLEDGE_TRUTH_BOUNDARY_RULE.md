# RULE

Knowledge base / playbook library / safe automation profile own:
- current canonical article truth
- current canonical playbook truth
- current canonical profile truth

Learning governance owns:
- feedback interpretation
- revision interpretation
- release and supersession interpretation

# CONSEQUENCE

A feedback record is not current article truth.
A revision request is not current profile truth.
