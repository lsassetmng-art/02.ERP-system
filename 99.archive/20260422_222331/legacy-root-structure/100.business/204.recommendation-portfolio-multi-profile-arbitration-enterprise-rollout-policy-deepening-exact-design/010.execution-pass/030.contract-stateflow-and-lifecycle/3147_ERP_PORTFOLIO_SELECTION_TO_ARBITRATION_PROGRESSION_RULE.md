# RULE

Portfolio selection may justify arbitration opening,
but portfolio truth does not disappear.

Progression should preserve:
- linked portfolio profile reference
- candidate profile count visibility
- portfolio priority visibility
- arbitration strategy visibility
- rejected arbitration trace when applicable
