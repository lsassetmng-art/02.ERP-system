# RULE

Lane assignment may justify org-level governance application,
but lane-assignment truth does not disappear.

Progression should preserve:
- linked lane-assignment reference
- org-policy reference visibility
- exception visibility
- org-review visibility
- rejected governance-apply trace when applicable
