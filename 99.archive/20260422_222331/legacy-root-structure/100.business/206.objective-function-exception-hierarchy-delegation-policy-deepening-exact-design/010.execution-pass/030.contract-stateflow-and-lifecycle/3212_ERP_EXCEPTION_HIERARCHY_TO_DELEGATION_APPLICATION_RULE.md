# RULE

Exception resolution may justify delegation application,
but resolution truth does not disappear.

Progression should preserve:
- linked exception-hierarchy reference
- linked delegation-policy visibility
- delegate eligibility visibility
- escalation requirement visibility
- rejected delegation trace when applicable
