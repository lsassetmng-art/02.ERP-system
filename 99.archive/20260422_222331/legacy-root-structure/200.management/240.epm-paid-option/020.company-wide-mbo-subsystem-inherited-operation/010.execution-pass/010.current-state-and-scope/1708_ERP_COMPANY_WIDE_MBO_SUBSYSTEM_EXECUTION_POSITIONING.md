# POSITIONING

company_wide_mbo is the ERP inherited-operation subsystem
for organization-wide goal rollout under EPM.

It owns:
- organization-wide MBO program truth
- objective cascade truth
- target assignment truth
- progress review truth
- evaluation support truth

It does not own:
- parent EPM objective architecture truth
- management decision truth
- labor employment truth
- independent personal_mbo truth
