# POSITIONING

Audit core is the ERP assurance,
evidence, finding, and conclusion truth layer.

It owns:
- audit engagement truth
- audit evidence item truth
- audit finding case truth
- audit conclusion record truth
- audit follow-up closure truth

Audit core does not own:
- governance policy truth
- management decision truth
- operational business truth
- labor operation truth
- accounting posting truth
