# ============================================================
# ERP FROZEN AUTHORITY CRITERIA
# ============================================================

status: canonical-draft
system: erp
owner: Boss
prepared_by: Zero

purpose:
Defines the criteria for promoting authority judgments
from draft state toward frozen authority decisions.

# ============================================================
# 1. CORE RULE
# ============================================================

core_rule:
No authority decision should be treated as frozen
from naming similarity or structural intuition alone.

Frozen authority requires evidence plus stability.

# ============================================================
# 2. MINIMUM CRITERIA
# ============================================================

minimum_criteria:
- semantic owner is stable
- physical role is classified
- conflicting candidates are reviewed
- at least one evidence pass exists
- unresolved risks are explicitly listed

# ============================================================
# 3. STRONGER CRITERIA
# ============================================================

stronger_criteria:
- write path is observed or strongly evidenced
- view/projection/support/history distinction is explicit
- direct competing authority candidates are narrowed
- contract alignment impact is understood
- dual-write risk is reviewed

# ============================================================
# 4. FROZEN-LEVEL CRITERIA
# ============================================================

frozen_level_criteria:
- repeated evidence supports the same authority judgment
- no stronger competing authority candidate remains
- major operational ambiguity is resolved
- registry classification is stable across related documents
- change risk from later review is low

# ============================================================
# 5. CONCLUSION
# ============================================================

conclusion:
Frozen authority is not just a strong guess.
It is a low-ambiguity, evidence-backed, stable working decision.
